1. 解锁密钥库

已迁移数据时，输入原密钥库密码即可。密码和 API 私钥只交给本机程序，不发送到 GitHub。

首次使用：配置两个账户

已有持仓请先迁移原账本，不要从空白配置重新开始。只填交易 API 私钥，不填钱包主私钥或助记词。

2. 检查账户

先检查余额、持仓、挂单和逐仓 3 倍设置。

3. 加载并启动

旧规则升级前，请停止旧程序并完成未结束的双腿操作。加载时保留持仓与历史，自动升级为 5U 网格、同价至少 30 分钟、每档最多 5 次；核对后再启动策略。

关闭浏览器后程序继续运行。重新双击 EXE 可打开本页面。

4. 飞书异常通知

此处只配置当前 OPENAI 标的的通知。开仓、加仓、平仓异常持续 60 秒未恢复才提醒；自动配平成功后撤销待发消息，不单独发送恢复通知。同一持续异常最多每 5 分钟提醒一次。账本写入失败、孤立仓位及总亏损保护仍立即提醒。两个标的可填同一个机器人和本人私聊接收 ID，需要分别保存。

配置飞书机器人

先在飞书开放平台启用机器人及发送消息权限，发布应用，并确保本人在机器人的可用范围内。密钥单独加密保存，重启后随本标的密钥库解锁。

请在手机确认测试通知收到。断网时重试并保留待发记录；程序退出、系统睡眠或断电时不能即时发送，重新加载后补发。队列最多 512 条，超出数量会在这里提示。
