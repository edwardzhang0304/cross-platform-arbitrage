# Console assets

- `glass-background.webp` and `brand-glass.png`: generated with OpenAI Image Gen for this application's selected glass-control-center design, 2026-10-22. They contain no account information. Background: 1487 × 1058; mark: 256 × 256 with transparency.
- `phosphor/`: Phosphor Icons web 2.1.2, MIT, from https://github.com/phosphor-icons/web (npm `@phosphor-icons/web`). Original license included. Regular font and CSS are bundled locally; font-face narrowed to the included WOFF2.
- All files are embedded into the local Rust server. The console does not load fonts, styles, icons or images from a CDN.
