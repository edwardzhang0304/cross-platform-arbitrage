# Lighter 账户权益修正（v0.1.1）

首次只读检查和实时通道失效后的账户刷新使用 REST `/api/v1/account`。
原代码用 `collateral + unrealized_pnl` 作为总权益；逐仓持仓已分配的
`allocated_margin` 不在 `collateral` 里，因此首次检查会漏显示这部分资金。

REST 现在直接采用平台返回的 `total_asset_value`，包含已分配的逐仓保证金及浮动盈亏；
实时通道继续使用 `user_stats.portfolio_value`。不再重复加减保证金或浮动盈亏。
可用资金仍单独取 `available_balance`，总权益不代表可用开仓额度。
缺少或无法解析总权益时拒绝本次账户证据，不回退到不完整的抵押余额。

此处仅修正账户权益读取。策略参数、订单执行、仓位数量、费用账本和密钥库
格式不变。升级时退出旧后台，仅替换 EXE，保留已有 `data` 目录。

回归覆盖：逐仓保证金不遗漏、浮盈不重复、REST/实时通道一致、零/负权益、
总权益字段缺失或损坏。测试使用虚构账户数值。
