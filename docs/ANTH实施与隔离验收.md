# ANTH 开发候选版与 Mac 模拟

日期：2026-09-27。分支：`feature/anth-paper`。候选版本：`0.2.0-rc.1`。

## 页面怎么分

同一个程序、同一个 `18794` 端口，两个独立页面：

| 地址 | 内容 |
| --- | --- |
| `/openai-inventory` | OPENAI 的账户、行情、组数与收益 |
| `/anth-inventory` | ANTH 的账户、行情、组数与收益 |

现在是 **Windows 跑 OPENAI 实盘，Mac 跑 ANTH 模拟**。Mac 页面明确显示“模拟账户 · 虚拟资金”。Mac 的 OPENAI 链接不会自动连接 Windows，也不会读取 Windows 的实盘账户。以后安排升级、录入新地址并验收后，Windows 新版才可以同时运行两个实盘策略。

## 配置和钱如何隔离

1. OPENAI 保留原来的配置、Vault 和账本位置，已有持仓单位仍是四位小数。
2. ANTH 实盘使用 `data/profiles/anth-live/`，其中 `config/profile.json` 是账户与策略配置，`keys/trading.vault` 是独立加密密钥库，`runtime/inventory.sqlite` 是独立账本。ANTH 的内部单位是五位小数。
3. 每个配置明确绑定标的、实盘/模拟、两个平台的账户别名、Lighter INDEX 和公开钱包地址。已有公开绑定不能静默替换。启动前检查两对是否复用钱包、INDEX 或账户别名。
4. 原 OPENAI 旧账本若缺少 Lighter 主地址，首次解锁时从已验证的 Vault 公共摘要生成 `config/account-bindings.json`，不改旧账本。完成这一步后才能登记另一对账户。
5. 页面各有独立控制接口和令牌；OPENAI 页的令牌不能用于 ANTH。关闭整个程序前要求两个策略都停止并完成双腿操作。锁定某一对只撤销它自己的执行权限。
6. 模拟版使用单独可执行文件和新数据根目录；没有 Vault、实盘适配器和实盘控制入口。配置填入真实账户编号、错标的账本、错模式目录或另一个平台的虚拟成交记录，都会拒绝加载。

当前 Mac 的虚拟数据目录：`/Users/zhangwentao/Documents/量化交易/ANTH-Mac模拟/data`。里面只有虚拟账户和模拟成交，不复制原 OPENAI 私人数据。

## 保留的规则

初始虚拟资金每平台 100U。参数取自当前 OPENAI 策略模板：首组 `max(MA5m, 5)`，5 秒双次确认，15U 名义仓位，逐仓 3 倍，最多 20 组，同价加仓至少 15 分钟、最多 5 次，网格步长 2，保留现有逐组平仓条件与 0.01% 保护限价。没有采用讨论中尚未确认的“24 小时衰减平仓”方案。

开仓、加仓、平仓、费用归属、未知成交查询、尾数恢复共用 Rust 内核。OPENAI 保持 `1/10000` 单位；ANTH 使用 `1/100000`，双腿共同步长是 `0.001`。例如 Lighter 部分成交 `0.00637`，会完整记录 637 个单位，不截成 `0.0063`。只有双腿真实/虚拟成交记录和每组数量一致，操作才可标记完成。

模拟 IOC 按当前盘口、保护价和精度匹配，支持部分成交；每个平台另存耐久成交记录，主账本重启后按原订单编号核对，避免重复下单。

## 模拟收益的限制

手续费按配置费率计入。资金费使用公开历史结算费率与对应时刻的虚拟持仓；Lighter 使用公开每单位结算金额，Entropy 缺少历史 oracle 价格时使用结算前一小时公开 K 线收盘价作为近似。因此页面标注资金费为模拟估算，不代表真实到账。接口缺失或覆盖不完整时不补零。

模拟没有排队、自己的市场冲击和真实签名延迟。逐仓强平按维护保证金和标记价做全平近似，模拟强平费率为 0.5%；不是平台真实强平引擎的逐项复制。

公开规格参考：[Lighter 合约信息](https://apidocs.lighter.xyz/reference/orderbookdetails)、[Lighter 资金费历史](https://apidocs.lighter.xyz/reference/fundings)、[Hyperliquid 永续接口](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/perpetuals)。启动时重新核对标的 ID、精度、最低数量与保证金模式，发现变化会拒绝启动。

## 验证范围

- OPENAI 原有规则和旧账本兼容性回归。
- ANTH 双向部分成交、接受后断线、原订单查询与重启恢复。
- 平仓五位尾数补齐，Entropy 对冲不得提前结束。
- 虚拟成交记录的标的/模式/平台绑定，主账本串用拒绝。
- 资金费正负方向、计价精度、结算时刻的虚拟持仓。
- 页面标的与模式核对，数量保留五位，净收益与平仓净收益分别显示。
- Mac 公开行情接入与真实运行中的虚拟配对持仓核对。
- Windows 候选包执行无密钥的启动、双页面、跨标的控制拒绝与退出检查。

**尚未进行 ANTH 实盘验收，也没有启用 ANTH 真实资金交易。** 新地址准备好后，再核对账户、签名授权、逐仓设置，并安排 Windows 升级交接。现有 Windows OPENAI 不自动更新。
