多平台套利 Windows rc.30

开仓与加仓使用两个条件。第一，两边分别有足够的实际可用资金支付新增仓位、成交成本及安全预留。第二，按保护价格计算整仓风险和额度。Lighter 逐仓检查现有权益和新增仓位的保证金。现仓略低于初始要求时，仅在加仓后的保证金比例改善、强平距离足够且账户资金充足时继续。Entropy 使用平台返回的可交易额度。程序在第一腿送出前并行复核两边账户、持仓、挂单和最新盘口。

本地资金检查未通过时跳过本次机会。若第一腿已成交，只撤回本次新增且未配平的数量。至少等待30秒，之后仍需重新满足信号、持仓核对和资金检查。正常平仓和止损可以在等待期间运行。已确认的平台保证金拒单继续要求人工核对，未知订单继续查询原单，连续回滚保护仍生效。

Windows 升级步骤
1. 将 ZIP 解压到桌面新的“多平台套利-rc30-Windows-x64”文件夹，先不要打开程序。
2. 在旧后台依次停止所有已加载账户。运行旧目录的 Run-Diagnostics.cmd，核对没有未完成订单、挂单或孤立仓位，两平台持仓与账本一致。已配平持仓可以迁移。如仍有待处理订单，先保留旧后台核对。
3. 点击“退出所有账户”，确认任务管理器中 Cross-Platform-Arbitrage 已退出。备份旧目录。
4. 将旧目录的整个 data 文件夹复制到新包 Cross-Platform-Arbitrage.exe 旁边。确认是“新程序目录\data”，避免 data\data。
5. 从新目录运行 EXE，在 Windows PowerShell 执行以下只读命令。应显示 0.2.0-rc.30，且 data_dir 指向新目录。PowerShell 5 中文路径显示异常时，可在控制台页面核对路径。
   Invoke-RestMethod 'http://127.0.0.1:18794/health' | Select-Object version,data_dir
6. 按原密码解锁，执行只读检查，加载原账户和账本，对照旧诊断的持仓、挂单及账户名称。
7. rc.29 已经保存的 ANTH 保护需要本人选择恢复方式。只管理原仓，就选“仅恢复平仓和止损（保留保护）”。需要恢复加仓，保持账户已停止，选“核对并解除开仓保护”。核对通过后仍需另行点击“启动策略”。核对失败时可以继续使用仅平仓和止损。其他账户逐一恢复原来使用的模式。
8. 运行新目录的 Run-Diagnostics.cmd 核对版本、持仓和状态。账户原有的飞书配置跟随 data 迁移，原本没有配置的账户仍需单独保存、启用并测试通知。

资金模型依据：Lighter 公开验证器 lighter-prover/fa85b331 的 circuit/src/apply_trade.rs（同向增加仓位的保证金增量）、circuit/src/matching_engine.rs（账户现金及逐仓风险的独立检查）和 circuit/src/types/risk_info.rs（整仓健康变化）。预检只使用已有授权的交易接口，查询到下单之间盘口和账户仍可能变化。
